L’architecture du système constitue une étape fondamentale dans la planification d’un projet web. Elle permet de définir la structure technique globale de l’application, en identifiant les composants essentiels, leurs rôles, et la manière dont ils interagissent entre eux. Concevoir cette architecture en amont garantit un développement plus cohérent, sécurisé, et évolutif.

Dans ce cadre, les étudiants doivent produire un schéma d’architecture du système pour leur projet web. Ce schéma doit représenter de façon claire :

    Le front-end (interfaces utilisateur et technologies utilisées),
    Le back-end (serveurs, APIs, logique métier),
    Les bases de données et leur type (relationnel),
    Les flux de données (requêtes, réponses, authentification),
    Et éventuellement les services externes (APIs tierces, cloud, etc.).

Ce travail de modélisation technique développe chez l’étudiant une vision globale du fonctionnement de leur application, tout en les préparant aux exigences d’un environnement de développement professionnel.
