Dans le développement d’un projet web, la conception back-end ne se limite pas à l’écriture de code serveur : elle commence par une modélisation rigoureuse des données que l’application devra manipuler. Cette phase est essentielle pour garantir un système cohérent, fiable et évolutif.

Les étudiants doivent concevoir :

1. Un modèle Entité-Association (E-A), qui permet de représenter de manière graphique les différentes entités (utilisateur, commande, produit, etc.) et les relations qui les lient (possède, commande, appartient, etc.). Ce diagramme sert de vue conceptuelle du système d’information.

2. Un modèle relationnel, qui traduit ce schéma en tables (relations) prêtes à être implémentées dans une base de données relationnelle (comme MySQL). Chaque entité devient une table avec des attributs, des clés primaires, des clés étrangères, et des contraintes d’intégrité.

Cette démarche permet aux étudiants de :

·       structurer proprement leurs bases de données,

·       anticiper les requêtes SQL nécessaires au bon fonctionnement du site,

·       et éviter les redondances ou incohérences de données.
