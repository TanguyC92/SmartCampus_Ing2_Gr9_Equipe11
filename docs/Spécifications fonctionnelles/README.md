La spécification fonctionnelle décrit, de manière claire et structurée, le comportement attendu du système du point de vue de l’utilisateur. Elle constitue le pont entre l’idée du projet et sa mise en œuvre technique, en permettant à toutes les parties prenantes (développeurs, enseignants, utilisateurs) de comprendre précisément ce que le site doit faire.

Dans ce contexte, les étudiants doivent rédiger une spécification fonctionnelle pour leur projet web. Celle-ci doit énumérer et décrire :

    Les fonctions principales (ex. : s’inscrire, rechercher un produit, envoyer un message),
    Les règles de gestion (ex. : un utilisateur non connecté ne peut pas commander),
    Les scénarios d’usage typiques (ou "cas d’utilisation"),
    Les interfaces prévues (avec les écrans à produire),
    Les contraintes techniques ou ergonomiques (ex. : responsive, accessibilité, sécurité).

Ce document aide les étudiants à clarifier leurs idées, à éviter les malentendus lors du développement, et à poser les bases d’un projet bien défini, testable et réalisable.
