Dans le processus de conception front-end, le storyboard occupe une place essentielle pour anticiper l’expérience utilisateur (UX) et planifier les interactions clés entre l’utilisateur et l’interface. Contrairement au wireframe qui se concentre sur la disposition statique des éléments d’une page, le storyboard permet de visualiser les scénarios d’usage, étape par étape.

Les étudiants doivent réaliser un storyboard illustrant le parcours d’un utilisateur dans leur futur site web. Il s’agit de représenter visuellement une suite d’écrans, accompagnée de brèves descriptions textuelles expliquant ce que fait l’utilisateur (clic, navigation, formulaire, etc.) et comment l’interface réagit.

Cette approche favorise une conception centrée sur l’utilisateur en permettant de mieux comprendre les besoins, les attentes et les blocages potentiels. Elle constitue également une base de discussion solide avant le développement du prototype fonctionnel.
