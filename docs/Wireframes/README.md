La conception front-end constitue l’une des premières étapes essentielles dans le développement d’un projet web. Elle vise à définir l’apparence visuelle, l’ergonomie et la structure interactive d’une application avant d’en entamer la programmation. Pour guider cette phase de réflexion, les étudiants sont amenés à créer des wireframes (maquettes filaires). Ces schémas simplifiés représentent l’agencement des différents éléments d’une page web (en-tête, menus, zones de contenu, boutons, etc.) sans se soucier du style graphique final. L’objectif est d’assurer une interface claire, cohérente et intuitive qui respecte les principes fondamentaux de l’expérience utilisateur (UX).

Un wireframe devra comporter :

    Un en-tête clair avec nom/logo du site
    Un menu de navigation
    Une zone principale de contenu
    Un ou plusieurs boutons d’appel à l’action (ex. : "S’inscrire", "Explorer", etc.)
    Un pied de page avec mentions ou liens

La réalisation de wireframes constitue une étape essentielle pour valider les choix de design et faciliter la communication au sein de l’équipe projet avant le passage au développement concret.
